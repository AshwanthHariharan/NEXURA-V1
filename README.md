# NEXURA - Smart Pill Dispenser

## Registration & Authentication Module

### Features Implemented

1. **Product Code Activation**
   - Enter product code (format: NEX123)
   - Validation and activation

2. **User Registration**
   - Full Name, Email, Mobile Number
   - Password with strength validation
   - Role-based registration (Patient/Caregiver/Admin)
   - OTP verification

3. **Login System**
   - Email login
   - Mobile login
   - Password validation
   - Session management

4. **OTP Verification**
   - 6-digit OTP generation
   - 5-minute expiry
   - Resend OTP functionality

5. **Forgot Password**
   - OTP-based reset
   - New password validation

6. **Multi-language Support**
   - 23 Scheduled Indian Languages
   - 5 International Languages
   - Persistent language preference

7. **Security Features**
   - Password hashing (SHA-256)
   - Session management
   - Secure storage
